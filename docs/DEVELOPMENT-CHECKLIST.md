# Pune development checklist

This is the persistent checklist for the user's requests, including the pasted handoff. Items stay open until their final integrated behavior is checked. A branch, a passing isolated test, or an announcement that work started does not establish that a feature is available on `main`.

## Current integration status

The eight compatible feature branches have been merged into local `main` with history preserved. The newer seven-rig resident set is retained alongside the three selectable looks. New atmosphere, urban workers/smoking, PANZER and reference-informed facade modules are wired into the game. Source integration is complete; see the final validation section for executed checks and any remaining limitations.

A separate [gameplay roadmap](GAMEPLAY-ROADMAP.md) tracks the user's later request for GTA-style systems. It includes the first wanted/search/surrender and versioned progress-save implementations while keeping production-scale systems open.

## Audit baseline and evidence

Source audit baseline: remote `main` at `6b7c70d` ("Merge the playable Pune streets into main"). The published local checkout was initially behind that baseline at `a108077`. The integration work following this audit may advance `main`; update this checklist after testing that result.

Status meanings:

- **Main / source present**: the behavior has a source implementation in the audit baseline. This document does not imply it passed a browser check in the current session.
- **Branch / integration pending**: a remote branch contains implementation and, where noted, tests. Its integration and combined runtime behavior are unverified.
- **New source / integration pending**: a new module was implemented during this development session and its focused tests passed; combined runtime behavior and merge into `main` remain unverified.
- **Partial**: a prototype or related behavior exists, with the remaining requirement stated explicitly.
- **Pending**: no implementation was found in the audited feature branches.
- **Reference blocked/unverified**: the required reference or asset has not been inspected or supplied sufficiently to make a fidelity claim.

## Integration notes and remaining limits

- Branch integration preserves tagged building heights, narrower road/lane/pavement alignment, varied inferred roofs and dense infill together. The old test requiring every infill height to equal12m was replaced with the valid neighboring-height range; tagged-height protection tests remain.
- Unified tilde commands support both original vehicle/weapon/health words and population/traffic/weather commands. Armored and emergency vehicles participate in entry selection. Shared glTF geometry survives character switching.
- New controls: festival selector; `CLOTHES`, `PANZER`, `WIND`, `CALM`, `SMOKE`, `BLUESKY`, `FOG`, `STORM`; scene wheel zoom with follow reset. PANZER firing remains a visual flash rather than projectile gameplay.
- Player exits choose an unoccupied pavement position, not a live traffic lane. The fallback spawn was corrected after road narrowing. UI settings remain usable before entering the game; Esc releases the on-foot pointer for UI controls.
- Street View observations guide two original material profiles in the target corridor. They do not establish exact real-world colors or reconstruct all19,850 buildings.
- Photorealistic people, genuine child/family assets, exact facades/interiors, advanced combat, emergency dispatch, and exhaustive city-event rules remain partial or open. The GTA-style roadmap records these explicitly.
